**Status: design only.** No production / runtime change. No API calls were run by this slice. No edits to `ChatService`, backend, frontend, runtime prompts, provider settings, `appsettings*.json`, `*.csproj`, tests, seed bank, character name bank, story-plan generator, validator, `Program.cs`, README, speech / TTS / STT. ## 1. Purpose

Two paid OpenAI live runs against the v3.1 bake-off prompt + scenarios have shipped (mp1 = `14731b3`, mp2 = `fcffafe`). Engineering passed both; story quality showed an honest 9 / 10 hard-gate score on each plan **but** also surfaced four NEW defect categories the v3.1 system prompt does not currently address, plus two pre-existing defects v3.1 already targets but did not eliminate:

- **NEW:** cross-language token leakage in narrative (`shimmering` inside Armenian prose, mp2 PA T3).
- **NEW:** fabricated Armenian morphology (`ձայնուֆով`, `բարենի`, mp2 PD T3 / PA T2).
- **NEW:** schwa-stem instruction silently ignored (`Հին կամրջի վրա…` in mp2 PD T1, where the prompt explicitly required `Հին կամուրջի…`).
- **NEW:** abstract moral / sentimental codas at closure (`տաքությունն ու բարությունը տարածելու համար`, mp1 PA T3).
- **PRE-EXISTING:** C13 short closure persists across both runs and on both plans (mp2 PA T3 ≈ 55w / 70-100 floor; mp2 PD T3 ≈ 50w / 100-130 floor).
- **PRE-EXISTING:** Plan A T2 choice block continues to assert a resolution the narrative has not staged.

The v3.1 prompt is therefore **not yet production-ready on gpt-4o** for the spoken-toy use case. This slice designs the smallest prompt-only delta (v3.2) that addresses these six defect families without touching the bounded-arc invariants v3 / v3.1 already established.

This is not a production change request. v3.2 lives in `tools/StoryModelBakeoff/` only. Runtime `ChatService` and the production system prompt stay untouched.

## 3. Defect inventory

Six defect families, lettered A–F, mapped 1-to-1 to rule blocks in § 5.

### Defect A — Cross-language leakage

- **Symptom:** A non-Armenian token appears inside Armenian narrative or choice text.
- **Quote (mp2 PA T3):** `Տերևի վրա ցողի կաթիլները՝ արևի տաք շողի ներքո, **shimmering**՝ ուղեկցեցին արագիլին դեպի երկինք։`
- **Why v3.1 didn't catch this:** v3.1 already says `Ոչ տառադարձություն, ոչ անգլերեն, ոչ ռուսերեն։` but the rule is one sentence buried in the language block, with no example pair, no fail-back recipe, and no per-token self-check. When the model reaches for an English-flavored adjective mid-sentence, the per-token bias overrides the prompt-level prohibition.
- **Severity:** MAX. Unacceptable in any spoken-toy rendering.

### Defect B — Fabricated Armenian morphology

- **Symptom:** A token that is not an Armenian word (invented suffix / stem / compound) appears in narrative.
- **Quotes:**
  - mp2 PD T3: `…նրանց համբերությունը ծածկեց շրջակա **ձայնուֆով**:` (`ձայնուֆով` is not a standard Armenian word)
  - mp2 PA T2: `Շնիկը ժպտում էր, նրա հնարամտությունը հիմա **բարենի** պես էր օգտագործվում։` (`բարենի` reads as a non-word; intended sense closer to `բարիքի պես`)
- **Why v3.1 didn't catch this:** there is no rule against inventing morphology. The v3.1 language block says "natural Eastern Armenian like a warm grandmother telling a story" but does not give the model a fail-back when it doesn't know a word's correct form. The model fills the gap by hallucinating morphology.
- **Severity:** HIGH. Indistinguishable from gibberish to a child listener.

### Defect C — Schwa-stem / PLACE_STEM compliance

- **Symptom:** Turn 1 first sentence drops a letter from the stem given in `PLACE_STEM`, despite an explicit per-scenario note requiring the schwa-NOT-dropping form.
- **Quote (mp2 PD T1):** `**Հին կամրջի վրա** մի փոքրիկ մողես էր ապրում։` and again `…լսել **հին կամրջի** ձայներն…`. The user-turn note explicitly says `plan.place-ը «հին կամուրջ» է — schwa-ՉԻ-ընկնող ձև` and lists allowed forms `Հին կամուրջի…`, `Հին կամուրջը…`, `Հին կամուրջի վրա…`.
- **Why v3.1 didn't catch this:** the system prompt's C16 wording allows `համարժեք հայերեն հոլովում` ("equivalent Armenian inflection"), which the model treats as license to drop the schwa. The schwa-NOT-dropping requirement lives in the per-turn note only, not in the system prompt; in long generation the system-prompt rule wins over the note.
- **Severity:** MEDIUM. Looks like a small grammar slip on paper; in audio it changes the recognizable stem of the place name.

### Defect D — Closure too short

- **Symptom:** Turn 3 body is below the lower bound of `TARGET_WORDS` even when the budget is moderate.
- **Quotes:**
  - mp1 PA T3 ≈ 52 words against a 70–100 floor.
  - mp2 PA T3 ≈ 55 words against a 70–100 floor.
  - mp2 PD T3 ≈ 50 words against a 100–130 floor (worst sample of the run; ~50% under).
- **Why v3.1 didn't catch this:** v3.1 closure block says `Թիրախային երկարությունը՝ TARGET_WORDS-ով նշված միջակայք (հայերեն բառեր)` — a soft "target," not a hard floor. By Turn 3 the model has the resolution beat in mind and reaches for closure; the soft target loses to narrative gravity.
- **Severity:** HIGH. C13 fails on every observed Turn 3 across two paid runs.

### Defect E — Weak moralizing / soft lesson

- **Symptom:** Turn 3 closes with an abstract sentimental coda ("…in order to spread X and Y") rather than a concrete final image.
- **Quote (mp1 PA T3):** `Նրանք հետագայում հաճախ էին հիշում այդ օրը՝ տաքությունն ու բարությունը տարածելու համար։`
- **Why v3.1 didn't catch this:** v3.1's anti-moralizing rule (C2) bans direct moral lessons (`ՉՎերջացնել քայլը ուղիղ բարոյական դասով`) but allows ambient warmth-and-kindness framing. "Spreading warmth and kindness" is not a direct lesson but functions as one for a 4–7-year-old listener.
- **Severity:** MEDIUM. Reads as soft moralizing in audio; clips the warmth the closure is supposed to create.

### Defect F — Plan A resolution seam (asserted, not staged)

- **Symptom:** Turn 3 names the resolution motif from `plan.resolutionStyle` in passing inside a longer sentence, instead of staging it as a discrete on-stage action.
- **Quote (mp2 PA T3):** `Նրա երջանկությանն ու խաղաղությանը ի պատասխան, շնիկը տերևը նվիրեց նրան՝ որպես փոքրիկ նվեր։` — the gift moment is compressed into a clause; the listener does not see it happen. Compounded by the Turn-2 choice block already asserting `արագիլը թռչում տուն` while the Turn-2 narrative still says the stork has nowhere to rest.
- **Why v3.1 didn't catch this:** v3.1's plan-adherence rule (G) requires resolution in `plan.resolutionStyle` style on Turn 3 but does not require staging. The model reads "resolve in style X" as "name X," not "perform X."
- **Severity:** MEDIUM. The story technically resolves, but the climax is unfelt.

## 4. Cross-defect observations

- **Two of the six defects (A, B) are language-correctness failures** (English leak, fabricated morphology). These are the clearest "must not ship" class in a spoken Armenian toy.
- **Two of the six defects (C, F) are instruction-following failures** where the model partially follows the rule but skirts a specific load-bearing constraint (schwa preservation, resolution staging).
- **Two of the six defects (D, E) are length- / shape-of-closure failures** that compound: a short closure (D) is exactly where an abstract coda (E) appears, because the model is "wrapping up early."
- **Three of the six defects can plausibly be addressed with the same fix shape:** rule + bad example + good example + fail-back recipe + self-check instruction. v3.1 used this shape successfully for C14 / C15 / C16; v3.2 reuses it for the new defects.

## 5. Proposed v3.2 rule blocks

Six rule blocks, one per defect. Each block proposes a draft Eastern-Armenian wording, a bad example sourced from mp1 / mp2, a good example, a placement decision (system prompt vs. user turn), and a risk note.

### R1 — Armenian-only lexical hard gate (defect A)

- **Targets:** defect A — cross-language token leakage (`shimmering`).
- **Bad example (mp2 PA T3):** `…արևի տաք շողի ներքո, **shimmering**՝ ուղեկցեցին…`
- **Good example:** `…արևի տաք շողի ներքո, **առկայծելով**՝ ուղեկցեցին…` (or `փայլուն-փայլուն`, `փայլում էին`).
- **Draft wording (system prompt — replaces / extends current `ԲԱՑԱՐՁԱԿ ԼԵԶՎԱԿԱՆ ԿԱՆՈՆ`):**

  ```
  ԲԱՑԱՐՁԱԿ ԼԵԶՎԱԿԱՆ ԿԱՆՈՆ (R1 — STRICT v3.2)
  - Քո ելքի ՅՈՒՐԱՔԱՆՉՅՈՒՐ բառը պետք է բաղկացած լինի ՀԱՅԿԱԿԱՆ տառերից
    (Ա–Ֆ, ա–ֆ, ՚, ՛, ՜, ՞, ։)։
  - ԱՐԳԵԼՎԱԾ. անգլերեն, ռուսերեն, ֆրանսերեն, որևէ լատինատառ բառ,
    որևէ տառադարձված օտար բառ (օր.՝ "shimmering", "magic", "okay",
    "ok", "shimmer", "shine", "глаза", "просто" — ոչ մեկը):
  - ԵԹԵ չգիտես հայերեն ճիշտ բառը — ընտրիր ավելի պարզ հայտնի բառ
    կամ արտահայտություն: ՕՐԻՆԱԿ.
      "shimmering" → "առկայծելով" / "փայլում էին" / "փայլուն-փայլուն"
      "magic"      → "կախարդական"
      "okay"       → ընդհանրապես բաց թողիր / "լավ"
  - Մինչ ուղարկելը ստուգիր. յուրաքանչյուր բառիդ մեջ կա՞ առնվազն
    մեկ հայկական տառ: Եթե ՈՉ — փոխիր:
  ```

- **Placement:** SYSTEM PROMPT. The rule is universal across scenarios.
- **Overconstraint risk:** LOW. Armenian-only is already the policy; v3.2 only strengthens enforcement and adds a fail-back recipe.

### R2 — No invented morphology (defect B)

- **Targets:** defect B — fabricated tokens (`ձայնուֆով`, `բարենի`).
- **Bad examples:**
  - mp2 PD T3: `…ծածկեց շրջակա **ձայնուֆով**:`
  - mp2 PA T2: `…հնարամտությունը հիմա **բարենի** պես էր օգտագործվում։`
- **Good examples:**
  - `…ծածկեց շրջակա **ձայների մեջ**:` (simple, known forms)
  - `…հնարամտությունը հիմա **բարիքի պես** էր օգտագործվում։`
- **Draft wording (system prompt — new section):**

  ```
  ՀՆԱՐՎԱԾ ՁԵՎ ԱՐԳԵԼՈՂ ԿԱՆՈՆ (R2 — NEW v3.2)
  - Մի՛ ստեղծիր նոր հայերեն ածանց, վերջածանց կամ բարդություն,
    որը ինքդ չես ճանաչում որպես հայտնի բառային ձև:
  - ԵԹԵ տատանվում ես բառի ճիշտ ձևի հարցում — ընտրիր ավելի պարզ
    հայտնի փոխարինիչ: ՕՐԻՆԱԿ.
      "ձայնուֆով" (չի կա) → "ձայների մեջ" / "շշուկների մեջ"
      "բարենի"   (չի կա) → "բարիքի պես" / "բարություն բերող"
  - Մինչ ուղարկելը ստուգիր. յուրաքանչյուր անսովոր ածանց բառին
    հայտնի՞ ձև է, թե հնարված: Կասկածի դեպքում — փոխիր ավելի
    պարզ բառով:
  ```

- **Placement:** SYSTEM PROMPT, immediately after R1 (same family — language correctness).
- **Overconstraint risk:** MEDIUM. The rule must not chill correct poetic morphology (e.g. instrumental `ձայնով` is fine; `ձայնուֆով` is not). The wording focuses on **uncertain forms**, not on suffix avoidance generally. Pair with a positive example showing legitimate morphology to anchor the boundary.

### R3 — PLACE_STEM exact first-sentence rule, schwa-preserving (defect C)

- **Targets:** defect C — schwa-stem violation (`Հին կամրջի` instead of required `Հին կամուրջի`).
- **Bad example (mp2 PD T1):** `**Հին կամրջի վրա** մի փոքրիկ մողես էր ապրում։`
- **Good examples:** `**Հին կամուրջի վրա** մի փոքրիկ մողես էր ապրում։` / `**Հին կամուրջի մոտ** մի փոքրիկ մողես էր ապրում։` / `**Հին կամուրջը** ձմեռային մեղմ լույսի տակ էր…`
- **Draft wording (system prompt — replaces current `ՎԱՅՐԻ ԽԱՐՍԽՄԱՆ ԿԱՆՈՆ` C16 with stricter version):**

  ```
  ՎԱՅՐԻ ԽԱՐՍԽՄԱՆ ԿԱՆՈՆ (R3 / C16 — STRICTER v3.2)
  - PLACE_STEM-ը տրվում է ՃՇՏՈՐԵՆ — բոլոր տառերն ընդգրկված:
  - Քայլ 1-ի ԱՌԱՋԻՆ ՆԱԽԱԴԱՍՈՒԹՅՈՒՆՈՒՄ PLACE_STEM-ի
    ՅՈՒՐԱՔԱՆՉՅՈՒՐ տառը պետք է հայտնվի — ՉԸՆԿԱԾ schwa, ՉՓՈԽԱՐԻՆՎԱԾ
    տառ, ՉԿՐՃԱՏՎԱԾ հիմք:
  - Թույլատրված ձև (PLACE_STEM = "հին կամուրջ"):
      "Հին կամուրջի վրա…", "Հին կամուրջի մոտ…", "Հին կամուրջը…"
  - ԱՐԳԵԼՎԱԾ ձև:
      "Հին կամրջի…", "Հին կամրջում…", "Կամրջի…"
      (բաց է թողել «ու» ձայնը — սա խախտում է կանոնը)
  - Մինչ առաջին նախադասությունը ուղարկելը ստուգիր.
    PLACE_STEM-ի ՅՈՒՐԱՔԱՆՉՅՈՒՐ տառը (օր. «հ», «ի», «ն», «կ», «ա»,
    «մ», «ո», «ւ», «ր», «ջ» — «հին կամուրջ»-ի համար)
    առկա՞ է առաջին նախադասությունում: Եթե ՈՉ — վերագրիր:
  ```

- **Placement:** SYSTEM PROMPT. The current per-turn schwa note for Plan D stays in the user turn as redundant reinforcement, but the load-bearing rule moves up.
- **Overconstraint risk:** LOW. The rule is already the operator's intent; v3.2 only makes it un-skirtable.

### R4 — Turn 3 length self-check + expansion (defect D)

- **Targets:** defect D — short closure on every Turn 3.
- **Bad examples:** mp1 PA T3 ≈ 52w / 70–100; mp2 PA T3 ≈ 55w / 70–100; mp2 PD T3 ≈ 50w / 100–130.
- **Good example shape:** if the natural closure body lands at 50 words against an 80-word floor, expand by adding one or two **concrete sensory or resolution sentences** before `Վերջ։`. Example expansion sentences: a sensory beat (`…քամին այգում մեղմորեն դիպավ տերևներին։`), a small character reaction (`Շնիկը հանգիստ շունչ քաշեց — սիրտը տաքացել էր։`), a final small image of the place (`Արագիլի ստվերն այլևս չէր երևում, միայն խնձորենու այգու հանգիստ լույսը։`).
- **Draft wording (system prompt — extends closure block):**

  ```
  ՓԱԿՈՒՄ — ՔԱՅԼ 3 (R4 — STRICTER v3.2)
  - Քայլ 3-ի մարմինը ՊԵՏՔ Է հասնի առնվազն TARGET_WORDS-ի
    ստորին թվին (օրինակ՝ 70-100 → առնվազն 70 հայերեն բառ;
    100-130 → առնվազն 100 հայերեն բառ):
  - Մինչ «Վերջ։»-ը ինքդ քեզ հաշվիր մարմնի բառերը: Եթե ստորին
    սահմանից ցածր ես — ՊԱՐՏԱԴԻՐ ավելացրու 1-2 ԿՈՆԿՐԵՏ
    զգայական/լուծման նախադասություն մինչ ավարտը:
  - Ընդունելի ընդարձակման տիպեր.
      ա. զգայական պատկեր (օր.՝ քամին տերևներին, ձայնի մարող
         արձագանք, լույսի փոփոխություն)
      բ. կերպարի փոքրիկ արձագանք (հանգիստ շունչ, ժպիտ, գլխի
         մեղմ թեքում)
      գ. վայրի վերջին պատկեր (օր.՝ խնձորենու այգու հանգիստ լույս,
         հին կամուրջի լռած փայտը)
  - ԱՐԳԵԼՎԱԾ ընդարձակում.
      • նոր արկած, նոր ընտրություն, նոր կերպար (արդեն C9-ով
        արգելված է — սա անգամ ընդարձակման համար ՉԻ թույլատրվում)
      • վերացական դաս կամ բարոյական կոդա (R5 ստորև)
  ```

- **Placement:** SYSTEM PROMPT (closure block).
- **Overconstraint risk:** MEDIUM. Forcing expansion when the natural arc is already complete may push the model toward filler. Mitigation: anchor expansion to **concrete sensory/character** beats, not summary or moral. R4 is also expected to help defect F (R6) by giving the staged-resolution rule more room to land within the budget.

### R5 — Concrete closure, no abstract sentimental coda (defect E)

- **Targets:** defect E — soft moralizing tail.
- **Bad example (mp1 PA T3):** `Նրանք հետագայում հաճախ էին հիշում այդ օրը՝ **տաքությունն ու բարությունը տարածելու համար**։`
- **Good example:** `Շնիկն ու շունը նստեցին ծառի տակ. արագիլի ստվերն արդեն երկնքում էր։` — concrete final image, no abstraction, no "in order to" framing.
- **Draft wording (system prompt — extends current `ՀԱԿԱ-ԲԱՐՈՅԱԽՈՍԱԿԱՆ ԿԱՆՈՆ`):**

  ```
  ՀԱԿԱ-ԲԱՐՈՅԱԽՈՍԱԿԱՆ ԿԱՆՈՆ (C2 — STRICTER v3.2)
  - ՉՎերջացնել քայլը ուղիղ բարոյական դասով (արդեն v3.1):
  - ՆՈՐ — ՉԵՐՋԱՑՆԵԼ վերացական զգացողական կոդայով, որպիսին.
      "հետագայում միշտ հիշում էին..."
      "...որպեսզի բարություն/սեր/տաքություն տարածվի"
      "...և մնաց պատմությունը մի սիրուն դաս"
      "...ընկերությունը մեծագույն գանձն է" և այլն:
  - Քայլ 3-ի ՎԵՐՋԻՆ ՆԱԽԱԴԱՍՈՒԹՅՈՒՆԸ ՊԵՏՔ Է լինի ԿՈՆԿՐԵՏ
    պատմողական պատկեր — մի կերպար, մի շարժում, մի զգացողություն
    ՀԵՆՑ ԱՅՍ ՊԱՀԻՆ:
  - Թույլատրված. զգայական պատկեր ("քամին տերևներին դիպավ"),
    կերպարի փոքր շարժում ("շնիկը հանգիստ շունչ քաշեց"),
    վայրի լույս/ձայն ("խնձորենու այգու լույսը մարող էր"):
  - Արգելված. "հետագայում", "միշտ", "որպեսզի...", "սովորեցին որ...":
  ```

- **Placement:** SYSTEM PROMPT (within or after C2).
- **Overconstraint risk:** MEDIUM. Banning `հետագայում` / `միշտ` framings could feel restrictive on age-7-richer mood. Mitigation: the rule targets framing of the **last sentence** specifically; the rest of the body may still carry general framing where it serves the story.

### R6 — Resolution staged, not asserted (defect F)

- **Targets:** defect F — `plan.resolutionStyle` named in passing rather than performed on stage.
- **Bad example (mp2 PA T3, resolutionStyle = `լուծումը գալիս է փոքրիկ նվեր մատուցելուց`):** `Նրա երջանկությանն ու խաղաղությանը ի պատասխան, շնիկը տերևը նվիրեց նրան՝ որպես փոքրիկ նվեր։` — gift compressed into a subordinate clause.
- **Good example:** `Շնիկը կամաց երկարեց ցողի կաթիլներով տերևը արագիլին։ Տերևի կաթիլները փայլեցին նրա ճանկերի մեջ։ Արագիլը գլուխը խոնարհեց — սա էր նվերը։` — three short sentences, the gift moment performed.
- **Draft wording (system prompt — extends `PLAN ADHERENCE` and closure block):**

  ```
  ԼՈՒԾՄԱՆ ՆԵՐԿԱՅԱՑՈՒՄ (R6 — NEW v3.2)
  - Քայլ 3-ում plan.resolutionStyle-ը պետք է երևա ՈՐՊԵՍ ԿՈՆԿՐԵՏ
    ՊԱՀ պատմողի մեջ — առանձին նախադասությամբ (կամ 2-3
    կարճ-կարճ նախադասությամբ), որտեղ կերպարը ՆԵՐԿԱ կատարում է
    լուծման գործողությունը:
  - ԱՐԳԵԼՎԱԾ. լուծումը պարփակել մեկ ենթադրական դարձվածքով
    (օր.՝ "շնիկը տերևը նվիրեց որպես նվեր" — սա անվանումն է,
    ոչ ներկայացումը):
  - Քայլ 2-ի ընտրությունները ՉԵՆ ԿԱՐՈՂ ենթադրել, որ smallProblem-ն
    արդեն լուծված է — Քայլ 2-ի ընտրությունները միշտ ենթադրում
    են, որ smallProblem-ը դեռ բաց է, քանի որ լուծումը կիրառվում
    է ՄԻԱՅՆ Քայլ 3-ում:
  ```

- **Placement:** SYSTEM PROMPT (between PLAN ADHERENCE and closure block).
- **Overconstraint risk:** LOW–MEDIUM. Staging adds 1–2 sentences to Turn 3 — likely helpful for R4 (closure floor) and harmless for closure ceiling.

## 6. Diff against v3.1 — what to add, replace, leave alone

### What to ADD (new in v3.2)

- **R2** (no invented morphology) — wholly new section, no precedent in v3.1.
- **R5 strengthening** (concrete-closure ban on abstract codas) — new subsection inside the existing C2 block.
- **R6** (staged resolution + Turn-2 choice constraint) — new section, no precedent in v3.1.
- **R4 self-count + expansion** — new subsection inside the existing closure block.

### What to REPLACE

- The current `ԲԱՑԱՐՁԱԿ ԼԵԶՎԱԿԱՆ ԿԱՆՈՆ` (one sentence, no examples) is **replaced** by R1 (rule + bad example + good example + fail-back recipe + self-check). v3.1 wording is a strict subset of R1, so this is additive in semantics, replacement in shape.
- The current `ՎԱՅՐԻ ԽԱՐՍԽՄԱՆ ԿԱՆՈՆ (C16)` is **replaced** by R3 (adds the schwa-NOT-dropping requirement and a per-letter self-check). The v3.1 wording's `համարժեք հայերեն հոլովում` clause is the loophole the model exploited in mp2 PD T1; R3 closes it.
- The closure block's soft `Թիրախային երկարությունը՝ TARGET_WORDS` is **replaced** by R4 (hard floor + self-count + expansion recipe).

### What to LEAVE UNCHANGED

- Bounded-arc invariants — MAX_TURNS, no choices on Turn 3, `Վերջ։` allowed (load-bearing C9).
- BREAK-GLASS CHOICE BLOCK byte-for-byte rule (C15) — held on both mp1 and mp2.
- Plan-adherence basics — hero / friend / place / magicalObject / smallProblem / goal / mood / resolutionStyle preserved across turns.
- Output format — body + blank line + choice lines on T1/T2; only body + optional `Վերջ։` on T3.
- C14 anti-meta-output — no Continued / Note: / Շարունակեց հեքիաթը... — held cleanly on both runs.
- Safety block (no violence, no fear, no abandonment).
- Forbidden-opener block (`Մի անգամ`, `Մի գեղեցիկ օր`, etc.) — held on both runs.

### Contradictions / edge cases to monitor

- **Age-4 simplicity vs. R6 staged resolution.** Age-4 wants short simple sentences. R6's "stage in 2–3 sentences" must be compatible — those sentences can each be short and simple. Phrasing R6 as "1 to 3 short sentences" instead of "a longer scene" prevents drift.
- **Age-7 richer mood vs. R5 concrete-closure.** Age-7 allows light poeticness. R5 bans abstract codas, not poetic imagery. The distinction: `տաքությունն ու բարությունը տարածելու համար` is abstract framing; `մարող լույսն այգում թեթևորեն շարժվեց` is concrete poetic — allowed.
- **R4 floor vs. natural arc.** If the natural arc closes cleanly at, say, 60 words against a 70-floor, R4 forces 1–2 extra concrete sentences. Risk of padding. Mitigation: anchor expansion to **sensory** and **character-reaction** beats — both are hard to feel as filler in audio.
- **R1 + R2 vs. legitimate poetic compounds.** Eastern Armenian permits compound forms the model may not see often; R2 must not chill these. Mitigation: R2 only fires on **uncertain** forms. The fail-back recipe ("if uncertain, use a simpler known phrase") preserves room for known compounds.
