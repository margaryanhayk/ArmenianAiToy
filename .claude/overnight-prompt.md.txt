### SLICE 1 — Game Mode Overhaul (HIGHEST PRIORITY)
Target: Make Game mode feel like a real interactive Armenian game for ages 4–7, not a one-shot chatbot answer.

Problems to fix:
- No clear game goal communicated to child
- No turn structure (setup → child acts → response → continue)
- Vague questions / ends too early
- Bad or unnatural Armenian
- No state continuity between turns

Requirements for the improved Game mode:
- Must support at minimum: guessing game, "find the object," counting/simple logic
- Each turn must have: short warm setup + one clear child action/question + continuation hook
- Armenian must be Eastern Armenian, natural, child-friendly age 4–7
- No formal/bookish Armenian, no Russian-calque phrases, no English-calque phrases
- No boring openers like "Ողջու՜յն, ես Արեգն եմ"

Test to write: Game mode produces at least 2 coherent turn-over-turn responses with continuation

### SLICE 2 — Armenian Language Quality Pass
Target: Audit and improve all system/mode prompts for natural Eastern Armenian.

Check for and fix:
- Formal register where casual is needed
- Russian-calque sentence structures
- English-calque phrases (calques like "կատարել գործողություն" instead of natural Armenian)
- Overused generic phrases ("մի գեղեցիկ օր", "ես Արեգն եմ և ուրախ եմ")
- Too-short or too-generic fallback replies
- Unnatural question forms for a child
- Story/Riddle/Game prompts that instruct in unnatural Armenian

Test to write: Prompt content tests that assert banned phrases are absent

### SLICE 3 — Riddle Mode Improvement
Target: Real back-and-forth riddle with hint system.

Requirements:
- Ask one clear riddle, DO NOT reveal answer
- Wait for child's guess (continuation turn)
- Wrong guess → gentle Armenian hint, not the answer
- Right guess → celebrate briefly, offer another riddle
- No story choice buttons in riddle mode
- No null leakage

Tests to write:
- Initial riddle output contains no answer spoiler
- Continuation with wrong guess returns a hint
- Continuation with right guess returns celebration

### SLICE 4 — Story Mode Quality Pass
Target: Natural fairy-tale Armenian, meaningful choices, clean continuation.

Requirements:
- No overuse of "մի գեղեցիկ օր"
- Choices must be real different actions (not fake synonyms)
- No malformed choice labels
- selectedChoice A/B must actually change the story direction
- No "null" leakage in choice fields
- Keep responses short enough for ESP32 display

Tests to write:
- choiceA and choiceB are non-null only when story branch makes sense
- selectedChoice changes story text meaningfully
- No "null" string in output
